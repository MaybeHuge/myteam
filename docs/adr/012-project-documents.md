# ADR-012：项目文档入口

状态：已实施。

项目详情增加“项目文档”页签，汇总独立项目文档和当前项目已有的需求文档。列表支持按标题、类型筛选和分页，需求文档直接打开原有文档，不复制正文或版本。仅需求文档编写者能看到尚未应用的草稿；其他项目读者只看到已应用的版本。

新建时默认归属当前项目：不关联需求时在已有文档草稿表创建独立项目文档；选择需求时使用既有需求文档创建流程，并以需求标题作为文档标题。需求已有草稿或固定文档时不可再次创建，提交时在项目写锁内再次检查。关联需求的文档继续采用原有草稿、应用、评审及修订流程。

独立项目文档复用需求文档的图文工具、节点校验和图片规则，手动保存，冲突时保留本地编辑；离开时提示未保存内容。具备需求编写权限的项目成员可以创建和编辑，验收中、已完成或归档项目只读。正文存储于 `RequirementDocumentDraft.content`，图片元数据存储于 `RequirementDocumentImage`，图片对象存储于现有私有 S3 桶；引用校验按项目和文档隔离。超过 24 小时的未引用图片可由 `storage:prune` 清理。

迁移扩展现有需求文档草稿和图片表，需求已应用版本及其历史引用保持不变。部署时需执行 `./scripts/pnpm.sh db:generate` 和 `./scripts/pnpm.sh db:migrate`。项目文档目前不支持把创建后未关联需求的文档再绑定到需求，也不建立独立项目文档历史版本。
