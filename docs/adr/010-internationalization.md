# ADR-010：简体中文与英语

日期：2026-10-29。状态：已实施。

## 范围

登录、账号管理、工作台、项目及成员、迭代、需求、任务与看板、用例、测试记录、缺陷、版本发布及协作界面支持 `zh-CN` 和 `en-US`。语言入口位于登录页和工作区顶部，默认中文；偏好保存在浏览器的 `myteam.locale`，支持刷新保留和跨标签页同步，存储不可用时仍可切换。

切换只更新界面，不重新挂载业务页面或清空未提交表单。Ant Design 的确认框、分页等组件文案同步切换。日期和相对时间采用当前语言格式，时间点仍按现有 `Asia/Shanghai` 时区显示。

项目名称、需求描述、用例步骤、成员姓名、评论、附件名等业务数据保留原文。状态枚举、权限、URL、业务编号和数据库结构不随语言变化。

## 实现约定

- `packages/contracts/src/i18n/en.ts` 集中维护英文文案，以现有中文源文案为稳定键，复用中英文业务术语。动态文案使用 `{{0}}` 等占位符，插值不处理用户文本。
- 前端组件调用 `useLocale()` 订阅偏好并通过 `t()` 渲染系统文案；模块级标签表用 `localizeLabels()` 保持实时切换，契约层原始标签保持兼容。
- 日期格式从 `getLocale()` 获取语言。只影响格式，不更改业务时间和计划日期。
- 请求携带 `Accept-Language`；错误过滤器按语言输出系统提示，保留原错误代码、详情结构和请求编号。测试记录候选项中的结果标签也按请求语言输出，前端对应缓存包含语言。
- 历史通知和动态错误通过已知系统模板本地化，姓名、标题等捕获值保持原文；未知文案原样回退。已显示的接口错误可随语言切回中文。
- 新增界面文案时同步补充词条。契约测试检查静态 UI 键覆盖、占位符一致性、语言协商、动态消息及用户数据保护。

## 验证

单元测试覆盖语言存储、跨标签页同步、存储受限、表单输入保留、模块级标签及英文相对时间。浏览器测试覆盖登录切换和错误、刷新保留、业务页面与状态、发布检查及窄屏入口；同时回归现有中文操作流程。

实际结果：37 项单元/契约、32 项真实 PostgreSQL/SeaweedFS 集成通过。全量 21 个浏览器场景中首轮 18 项通过；取消按钮定位、保留数据下的工作台断言调整后复验通过，需求历史页签独立复验通过。英文窄屏布局修正后，英文业务页场景最终通过，覆盖迭代、需求、任务、用例、记录、缺陷、版本和成员页面。截图为 `test-results/i18n-english-mobile.png`。

无需数据库迁移，不增加账号级语言设置，不调用外部翻译服务。
