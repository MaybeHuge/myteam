# M2-02 任务拆解与分配验证

日期：2026-10-27。范围：功能/维护类需求下的任务、责任分配、估算/截止日、基础开始及协作接入。

## 1. 已实现

- Task 以同 ID 扩展 WorkItem，同项目复合外键关联需求，固定创建后的需求关联；项目内 TASK 编号在事务内递增，失败回滚编号。
- 维护任务标题/说明、优先级、估算小时、截止日、独立任务迭代。估算可空，0—10000 小时、0.25 小时粒度；截止日可空且须为合法日历日期。
- 开发可创建本人或未分配任务，维护本人负责或本人创建且未分配的待开始任务；项目负责人可以指派/改派，开发可认领未分配任务。分配/改派/认领必须说明原因。
- TODO → IN_PROGRESS 的开始检查：需求 CONFIRMED/IMPLEMENTING、已有可用且具任务权限的负责人、项目 ACTIVE、已安排的任务迭代 ACTIVE。本人执行或负责人附原因代理；首次开始同步需求 IMPLEMENTING，保留内容 revision 和评审快照。
- 修改、分配、开始均校验版本，幂等重放重新验证权限/责任范围；业务、父需求状态、审计、去重通知及幂等在同一事务。
- 改派保留前后值和原因，通知新旧负责人并排除操作者；未结束任务保护负责人移出、停用或收回任务权限。有未结束任务的需求不能直接取消。
- 任务与需求均保持 OPEN，不能直接清空已有迭代绕过关闭门禁；调整计划需原因，进行中任务只能转入进行中迭代。
- 项目任务列表、详情/编辑抽屉、需求拆分及关联入口、任务历史、筛选/分页与 URL 恢复、评论和 SeaweedFS 授权附件。

## 2. 新增检查

2 项契约检查：关联需求必填、默认值及状态不可注入、估算与日期边界、更新/分配版本、分配原因、开始命令不能写后续状态、TASK 协作目标。

16 项真实数据库/资源集成检查覆盖：

1. 两项目与管理员、负责人、产品、开发、测试、只读、非成员隔离。
2. 功能/维护类需求下拆分任务，默认计划、同 ID WorkItem、项目内编号、创建幂等及防止输入跳状态。
3. 无效/跨项目/不可用/无任务权限的负责人、跨项目需求、结束需求、关闭迭代，失败不消耗编号。
4. 开发本人/未分配创建与维护边界，不能替他人分配或编辑他人任务。
5. 原因必填、并发认领只有一人成功、不能抢占、开始后旧认领命令仍可安全幂等重放。
6. 改派前后值及原因、单条审计、双向通知和新旧负责人权限即时变化。
7. 开始前需求、负责人、项目、任务迭代检查；有未结束任务的需求不能取消。
8. 本人开始/负责人代理原因、需求实现中联动、基线不变；状态、负责人、需求关联不能通过普通更新偷偷改变；没有人工完成入口。
9. 同版本并发编辑、不能清空已有迭代、调整需原因、进行中任务不能移入规划迭代。
10. 搜索、编号、组合筛选与分页、互斥筛选无结果、合资格候选分页/搜索、开发候选仅本人、历史分页。
11. 未结束任务负责人移出/停用/失权保护，改派后正常退场。
12. 创建和开始的事件失败回滚任务、编号、父需求状态、审计、通知和幂等，修复后重试成功。
13. 改派通知失败整体回滚，原责任人及历史不变。
14. 真实任务阻止关闭迭代，数据库拒绝错误 WorkItem 类型、类型篡改和跨项目需求关联。
15. 真实 SeaweedFS 任务附件上传/下载、评论及目标授权，非成员/只读写拒绝，结束后协作只读但仍可下载。
16. 角色收回拒绝旧成功命令重放，项目进入验收后任务只读。

1 项新增浏览器流程演示：需求下建立任务（估算、截止日）→ 开发认领 → 未确认需求开始被拒绝 → 确认需求 → 本人开始及维护 → 负责人改派 → 原负责人失去编辑权限 → 历史前后值 → 协作入口 → 只读隔离 → 筛选刷新、桌面和窄屏；包含运行时及非预期控制台错误检查；关闭详情、筛选导航和项目视图切换均等待对应状态完成后再继续，避免刷新或进入详情抢先读取旧 URL。浏览器总超时随新增场景调整为 240 秒，单项任务流程上限 90 秒，未使用重试掩盖失败。
