# M5 简化交付验证

日期：2026-10-29。现行范围与决策见 [ADR-009](../adr/009-simple-release.md)。

- 发布检查：在隔离 PostgreSQL 中验证未完成需求、严重缺陷和旧范围构建会阻止发布；处理后可重新检查。重复缺陷关联其他需求的主缺陷时，按主缺陷状态判断。
- 生命周期：发布失败保留历史，重试成功后登记上线验证失败、通过及回滚；回滚后恢复为未发布。记录只追加，直接更新或删除受数据库约束保护。
- 事务与权限：相同幂等键不重复登记；相同版本的并发提交仅成功一次；无权限成员不能登记，非项目成员不能查看。提交时重新检查范围与需求，旧检查不能绕过服务端规则。
- 浏览器：在隔离测试项目中完成选择构建、检查、登记失败与成功、上线验证及回滚；检查窄屏抽屉范围。
- 这不是实际部署、生产验证或容量测试。未执行自动化部署，所选构建与测试记录的实际部署一致性由发布负责人核实。

本地业务数据库已应用增量迁移 `202610290014_simple_release`；迁移前后账号、项目、需求、任务、用例、测试记录、缺陷、版本、构建和附件数量一致。当前应用的版本详情、发布检查和交付记录接口均返回 200。该检查没有登记实际发布。
