# 任务与测试记录调整验证

日期：2026-10-28。现行业务基线为 [ADR-008](../adr/008-lightweight-testing-records.md)。

## 实现范围

- 任务只公开待开始、进行中、完成，负责人可完成、重新开始和退回待开始；三列看板与筛选一致。
- 需求根据任务、本轮全部未废弃关联用例的最新有效结果和阻断缺陷自动汇总状态，同步 WorkItem.OPEN/DONE。
- 测试记录代替提测和批次页面，从用例发起，保留多次测试、环境、可选构建、修订快照、实际表现和附件。
- 未通过自动创建或复用缺陷。复测失败重开，通过关闭，主缺陷变化同步影响重复缺陷所在需求。
- 手工缺陷可不关联用例/记录/构建；关联记录自动补齐用例，拒绝跨项目和不同需求的证据。
- 需求/用例修订、新增或重新开始开发工作、版本范围变更都不能沿用失效通过结果。

## 数据迁移

业务数据库已应用 202610280012_lightweight_testing 和 202610280013_test_record_guards。按用户明确授权清理旧提测、批次、测试结果及缺陷历史。账号、项目、需求、任务、用例、版本和构建保留；旧任务测试状态映射为开发完成，旧取消任务不进入公开三状态列表及需求统计。

迁移是增量执行，没有重建业务数据库，也没有向业务库重新填充演示数据。对象存储中的旧孤立对象可沿用现有 storage:prune 清理。

## 验证范围

真实 PostgreSQL 和 SeaweedFS 集成覆盖任务责任、自动状态、无任务/无用例/未执行门禁、共享用例按需求隔离、多轮缺陷修复、截图上传及附件授权、并发/幂等、不可覆盖证据、事务回滚、重复缺陷联动及构建失效。

浏览器验证使用独立测试库，覆盖开发和测试角色从任务完成到需求完成的实际操作、从用例发起记录、上传截图、自动建缺陷、修复复测、关联互跳、只读访问、桌面和 390px 窄屏。账号登录本身由既有身份场景覆盖。

## 2026-10-29：范围失效后的复测

- 版本仅修改名称或说明、关联范围不变时，范围版本与现有测试记录保持不变；实际范围变更仍使旧构建与测试依据失效。
- 待复测时开发负责人可确认并更新实际修复构建，系统校验项目、目标版本、当前范围及待完成复测记录；原历史不改写。
- 隔离测试覆盖权限、旧构建拒绝、幂等、待测试记录冲突，以及浏览器从更新构建到复测通过的流程。
