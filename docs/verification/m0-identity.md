## 5. 本次处理的环境问题

- Docker WSL 集成不可用：采用独立真实 PostgreSQL，本机和测试库分离。

- Chromium 缺少 NSPR/NSS/ALSA 和中文字体：使用项目级库和字体，检查桌面/窄屏截图。
- Ant Design 两字按钮可访问名称包含空格：测试按实际可访问名称匹配，不依赖内部 CSS 类。
