# M1-04 通用业务支撑验证

日期：2026-10-27。范围：评论、授权附件、事务审计与站内通知基础，当前接入项目和迭代。

后续存储变更：已按用户要求移除本地适配器，统一使用 SeaweedFS S3；本记录保留首批验证历史，现行存储与最新检查见 [资源存储验证](seaweedfs-storage.md)。

## 1. 交付内容

- 项目「讨论与附件」及迭代详情内的独立协作记录，评论为 1—5000 字纯文本，支持稳定分页和权限反馈。
- 图片、PDF、UTF-8 TXT/Markdown 上传，单文件 1 字节至 20 MiB，扩展名须符合识别内容；拒绝 HTML/SVG、非法编码和路径文件名。
- 附件私有保存，列表不返回存储键；下载重新校验当前项目、目标存在性及会话，以流返回 UTF-8 文件名、attachment 和 nosniff。
- 所有业务角色可以新增协作内容；只读成员只能查看。已关闭迭代、完成和归档项目只读，历史附件仍可授权下载。
- 评论/附件通知当前对象负责人；迭代创建、修改/改派、启动及关闭通知当前迭代负责人，排除操作者本人及不可用接收者。
- 顶部通知入口、可见未读数、分页、仅未读筛选、首次已读时间和对象跳转；30 秒查询且页面隐藏时暂停轮询。
- `CollaborationEvents.record` 供后续模块在业务事务内复用。审计、通知、幂等及业务一起提交；一般上传失败清理文件，崩溃遗留可用 `storage:prune` 按 24 小时保护窗口清理。

## 2. 数据与接口

第四个迁移：`202610270004_collaboration`，新增 Comment、Attachment、Notification 及目标枚举；不覆盖账号、项目或迭代数据。业务库不添加演示评论、附件或通知。

接口及授权见 [通用契约](../api-conventions.md#通用协作与通知m1-04)。目标类型目前仅接受 PROJECT/ITERATION，目标归属和状态在项目事务锁内复查。后续领域接入须扩展服务端目标授权；详情内容和附件不接受客户端指定存储位置。
