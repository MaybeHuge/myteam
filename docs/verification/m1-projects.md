# 项目、成员与界面打磨验证

日期：2026-10-27。范围：M1-02，以及本批配套的账号创建与界面精细化；M1-05 仍有后续工作。

## 1. 实际交付

- 项目创建、列表/卡片、详情、信息编辑、主负责人移交、启动/暂停/继续。
- 可见范围内的真实统计，关键词/状态/我负责/我参与筛选和分页。
- 现有账号加入项目、兼任角色、角色调整和移除，成员分页。
- 项目列表、详情、成员、动态及所有写操作执行服务端授权。
- 非成员隐藏资源；只读成员不可写；角色收回后无法重放旧幂等结果；已归档项目只读。
- 主负责人不能直接移除/降为无负责人角色，负责未结束项目的账号不能直接停用。
- 系统管理员可创建普通账号，系统管理员跨项目访问有审计。
- 独立 Infrastructure/Identity/Projects Nest 模块，新增迁移保留原用户与会话数据。
- 工作台、项目网格/表格、详情、成员、账号界面统一样式和反馈，窄屏适配。

## 3. 权限与一致性证据

apps/api/test/projects.integration.mjs 验证：

1. 普通成员的项目列表与统计仅包含其所属项目。
2. 跨项目详情、成员、动态和写入均被阻止；不存在与无权限返回一致提示。
3. 只读成员直接请求更新、启停、成员添加/角色/移除均失败。
4. 管理员创建和跨项目访问按约定留痕，普通成员不能创建项目或系统账号。
5. 日期/标识错误、重复标识和重复成员被拒绝，幂等重试只产生一次结果。
6. 同版本并发编辑一项成功、一项冲突；标识不可通过普通编辑更改。
7. 生命周期仅允许当前已实现的启动、暂停、继续，不允许跳到完成。
8. 主负责人保护、角色兼任、角色收回即时生效及旧幂等重放拒绝。
9. 移除成员后旧会话不能访问，重新加入后旧角色表单仍冲突；停用账号不能加入，已归档项目不能写。
10. 主负责人移交后新负责人获得角色，原角色保留；停用账号撤销会话。
11. 创建普通账号不能通过额外参数提升管理员权限；密码使用 Argon2id，幂等比较不保存明文或快速密码指纹。

## 4. 浏览器实际流程

管理员登录 → 新建普通账号 → 查看项目空间 → 切换列表/卡片 → 无结果筛选/清除 → 新建项目并选主题/日期 → 启动项目 → 加入只读成员 → 新上下文登录成员 → 查看但无管理按钮 → 直接请求写入返回 403 → 管理员移除成员 → 原会话读取返回 404 → 窄屏浏览且整页无横向溢出。

正常流程未出现 pageerror；检查了加载、空态、错误、角色选择、确认操作、桌面和窄屏截图。

## 6. 追加优化：添加成员下拉选择（2026-10-27）

- 添加成员由输入完整邮箱改为下拉选择已有账号，默认展示候选项，支持按姓名或邮箱搜索、键盘选择、分页滚动与加载更多。
- 候选项展示头像、姓名与邮箱；服务端排除当前项目已有成员和已停用账号，仅返回 `id/name/email`。
- 新增 `GET /projects/:id/member-options`，只向具有成员管理权限的人及系统管理员开放；普通开发/只读成员返回 403，非成员返回 404，归档项目返回 403。
- 每次重新打开添加抽屉重置选择和默认角色，避免快速连续添加时沿用上次表单；输入防抖与请求取消避免旧搜索结果覆盖当前输入。
- 写入继续复用现有邮箱添加命令、事务授权和幂等约定，不改变数据库结构。
- 本次静态/类型/构建与 5 项契约检查通过；35 项数据库集成检查通过，新增 2 项覆盖候选过滤、分页、姓名/邮箱搜索、最小字段和权限边界。浏览器原账号 2 项通过，扩展后的项目/成员用例定向回归通过，当前共 43 项自动化检查通过；本次没有重跑完整 check:ci。
- 浏览器覆盖默认候选、无匹配、邮箱与姓名搜索、键盘选择、添加后排除、再次打开重置、移除后重新可选与窄屏显示。
