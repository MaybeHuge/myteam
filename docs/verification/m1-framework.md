# M1-05 应用框架与待办容器验证

日期：2026-10-27。范围：现有模块的导航、项目切换、当前待办、列表上下文、错误与会话反馈；需求和任务仍待 M2。

## 1. 已实现内容

- 工作台前置「我的待办」，目前接入本人负责的未关闭迭代，按当前领域状态查询，提供规划/进行中/逾期筛选、关键词、分页、真实统计和详情跳转。
- 管理员同样只查看本人负责并仍有成员关系的迭代；只读成员可以查看自己的跟进，不能因此获得迭代管理权限。
- 改派和关闭即时使待办消失，旧未读通知不会把已关闭事项重新计入。待验收/完成/归档项目隐藏，暂停项目保留安排。
- 上海时区的截止日次日才算逾期，列表和统计在同一事务快照中查询。
- 顶部提供授权项目搜索、分页与切换，保留共用页签，清除前项目的详情、筛选及表单状态；详情组件按项目 ID 重新挂载。
- 项目、迭代、成员、账号和待办的筛选/分页使用 URL；从项目列表进入详情、换页签及刷新后返回，保留原列表搜索和视图。
- 统一安全页码范围，合法但越界的页面提供返回第一页；成员列表增加项目内姓名/邮箱搜索。
- 查询和写入的 401 统一清理缓存并退出，权限不足保留有效会话；项目加载失败可重试，未知页面提供明确 404 返回入口。
