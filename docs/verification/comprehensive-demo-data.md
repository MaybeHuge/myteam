## 数据保留

当前 .env 设置 KEEP_TEST_DATA=true。集成测试结束后保留领域记录、审计和 S3 对象，但正常关闭临时应用、连接和存储客户端；浏览器启动夹具也跳过旧领域数据清理。固定登录夹具的登录前置条件仍会恢复，测试自身验证的取消、停用、删除和回滚操作仍照常执行。

回归记录保存在 myteam_test / my-bucket-test；便于现有账号直接查看的中文数据新增在 myteam / my-bucket。原有业务项目和附件未删除，生成之前已保留完整 SQL、配置和附件备份。生成过程中保留了一份初始化阶段项目，命名为“【演示】计划准备与空态”，用于查看尚未提交需求时的界面。
