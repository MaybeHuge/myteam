# M3-01/02 用例库与评审修订验证

日期：2026-10-27。范围：M3-01、M3-02。完整 check:ci 退出码 0，M3-01/02 范围验证通过。

## 实现

- 用例库列表、标题/前置条件、有序步骤及预期、负责人、优先级、多需求关联、搜索/筛选/分页/URL；需求详情可直接创建并预选关联需求。
- 草稿允许不完整；送审及通过要求有效负责人、至少一步、每步操作及预期齐全。只能关联本项目已确认或实现中的需求。
- 指定评审人提交、通过、退回、撤回、废弃；退回/撤回/废弃须原因。管理员代评需说明并留痕。
- 每次内容保存追加修订快照，已通过内容修改须发起新修订并重新评审；历史内容及结论禁止覆盖。
- 需求修订事务同步标记关联用例需重新评审并增加版本。重新确认需求不会恢复旧资格，重新保存/修订并通过后才可使用。
- `selectUsableRevision` 在调用方授权事务内重新校验当前修订、评审结论及全部需求令牌，供 M4 正式选择使用。
- 复用 SeaweedFS 私有附件、评论、事务审计及评审通知；负责人/待评审人有移除、停用和失权保护。用例不影响开发任务独立推进。
