扩展检查验证六类当前待办归属；关联已有缺陷的原子失败记录及数据库延迟约束；源用例修改不改变旧执行快照，新修订重审后进入新构建批次；版本范围变化后待验收事项回开发；实际已发布版本的生产来源字段；OpenAPI 质量接口。已经失败的修复构建不能经改派后再次提交修复，旧 PASS 被新 FAIL 取代后不能用于关闭缺陷。
